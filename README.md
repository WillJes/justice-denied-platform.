# Justice Denied — Official Film Platform

A responsive documentary platform for **Justice Denied**, created for filmmaker and transformational speaker Jestina Weems-Rosenduft.

## Included

- Cinematic documentary homepage
- Official YouTube teaser
- Case and production archive cards
- Festival submission and selection tracker
- Guest-speaker booking section
- Donation and sponsorship area
- Mobile navigation and accessible page structure
- GitHub and Vercel deployment setup

## Start locally

Install Node.js 22 or newer, then run:

```bash
npm install
npm run dev
```

Open the local address shown in the terminal.

## Customize

Read [CONTENT-GUIDE.md](CONTENT-GUIDE.md) first. Most wording and links are in `app/page.tsx`; styling is in `app/globals.css`.

## Deploy

Follow [DEPLOYMENT-GUIDE.md](DEPLOYMENT-GUIDE.md). The included `vercel.json` tells Vercel to build this as a Next.js site.

## Important

The donation button is intentionally a placeholder until Jestina adds her preferred payment or fundraising link. Redact all private information before adding public case records.
